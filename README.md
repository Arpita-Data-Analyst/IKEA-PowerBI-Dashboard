# IKEA Power BI Dashboard

## Project Overview
This project presents an interactive Power BI dashboard focused on business performance and customer analysis.

## Dashboard Features

### 1. Business Overview
- Total Customers
- Total Revenue
- Churn Percentage
- Average Customer Value
- Revenue by Customer Segment
- Monthly, Quarterly and Yearly Revenue Trends

### 2. RFM Analysis
- Recency, Frequency and Monetary Analysis
- Customer Segmentation
- Segment Performance Summary
- Customer Value by Segment
- Customer Churn Analysis

## Tools Used
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- RFM Analysis
